# Cobertura del desafío y ensayos

Referencia: texto íntegro provisto por el usuario en el adjunto 0946f6a1-f68a-425b-8f01-7d3a4ff76400. No exige igualar todas las dimensiones, usar ML ni cubrir todo el mundo para una solución válida. Sí pide justificar analogía, diferencias y utilidad científica/operacional; nuestra aspiración de búsqueda global sigue pendiente.

Se incorporan ocho ejes en analogyScope.ts y nueve perfiles seleccionables en Comparación científica. Únicamente analogía topográfica regional permite cálculo hoy. Los restantes muestran datos faltantes y bloquean el cálculo para no presentar pendiente/rugosidad como validación mineralógica, biológica, térmica o geotécnica. Exportación JSON incorpora perfil, dimensiones y límites. Esto es control de alcance, NO integración de nuevos datasets.

- Terreno: elevación, pendientes, rugosidad y desnivel regional disponibles. No hay clasificación de cráteres, bloques ni peligros de aterrizaje.
- Geología/materiales: pendientes mapas compatibles, espectros y muestras. SIGAM/USGS, CRISM/M3 son fuentes propuestas, no medidas integradas.
- Térmico/iluminación: pendientes series de superficie con QA, estación/hora solar, geometría y modelo instrumental. MOD11A1/Diviner propuestos.
- Recursos: pendiente comparar hielo/agua/permafrost con profundidad, estación y evidencia explícitas.
- Procesos: pendiente series y tasas; separar procesos actuales/pretéritos y mecanismos distintos (la Luna no tiene erosión eólica atmosférica).
- Biología: pendiente observación de campo/laboratorio. Vegetación o aridez no demuestran biofirmas ni habitabilidad.
- Subsuelo: pendientes inventarios, mediciones y geometría; una entrada visible no acredita continuidad de una cueva.
- Operaciones: pendientes resistencia, tracción, instrumentación, comunicaciones y restricciones de campo. Relieve de 2 km no certifica movilidad de rover ni aterrizaje.

Todas las fichas de perfil indican propósito del ensayo y límites terrestres: gravedad, atmósfera/vacío y radiación. No se agregan puntajes cero para dimensiones ausentes ni se entrena el ML sobre columnas ficticias. Los tres clusters siguen describiendo solo relieve de una región.

Siguientes integraciones, con contrato por observación (unidad, escala, fecha, geometría, fuente, calidad, observado/derivado/inferido): primero cobertura de agua/vegetación y geología para interpretar candidatos; después perfil térmico separado; recursos y procesos con cobertura compatible. Biología, subsuelo y geotecnia requieren fuentes especializadas y validación de campo. Comparar distribuciones y condiciones de ensayo, no solo promedios ni códigos de unidades geológicas.

Validación independiente de cada perfil antes de habilitar su ranking; no trasladar automáticamente tolerancias o pesos topográficos a otros dominios. Datos propuestos no cuentan como evidencia. La búsqueda global, nuevos datos y generalización del ML siguen pendientes.
