# Explorador global

Atlas auxiliar, fuera de la entrega (D-023): se movió desde data/ para que el deploy
no publique una página sin su archivo de datos. Para abrirlo localmente, copiar
global-terreno.js desde el espacio compartido del equipo a esta carpeta y abrir atlas.html. El archivo pesa 33 MB y está excluido
de Git. Contiene los modelos MOLA, LOLA y ETOPO de la corrida exploratoria.

El explorador calcula un ranking regional separado de los perfiles de misión.
El zoom amplía la grilla existente. Este visor todavía no incorpora teselas de
mayor detalle ni terreno con geometría 3D.
