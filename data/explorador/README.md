# Explorador global

Atlas auxiliar, parte de la entrega (D-026). Vite publica esta carpeta y el atlas
se abre en /explorador/atlas.html. global-terreno.js (33 MB) está en Git y contiene
los modelos MOLA, LOLA y ETOPO de la corrida exploratoria.

El explorador calcula un ranking regional separado de los perfiles de misión.
El zoom amplía la grilla existente. Este visor todavía no incorpora teselas de
mayor detalle ni terreno con geometría 3D.
